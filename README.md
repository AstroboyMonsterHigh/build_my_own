# 🍳 Practice Project: Recipe Website

## 📌 Project Overview
This project is a standalone, static recipe website built from scratch using HTML5 and CSS3. The purpose of this project is to synthesize and apply foundational web development concepts learned during my journey through the Codecademy Full-Stack Engineer Path.

## 🎯 Learning Objectives Achieved
Based on my current progress in the Codecademy syllabus, this project demonstrates proficiency in:
- **Semantic HTML5:** Structuring recipe data logically using headers, lists, sections, and tables.
- **Fundamentals of CSS:** Utilizing selectors, cascade rules, and the box model for layout control.
- **Improved Styling:** Implementing custom color palettes and intentional typography hierarchy to enhance readability and user experience.
- **Local Development Workflow:** Building and managing the project locally within a dedicated development environment.

- HTML5

- Google Fonts (Typography practice)
